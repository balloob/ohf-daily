# Track: contributors and maintainers

Notice first merged contributions, sustained work across related PRs, and the human review that helped work land. Celebrate first contributors warmly and precisely using only authoritative cached fields. Credit human reviewers and approvers; exclude bots and never invent personal details.

Community is a lens that can enrich another article, not a mandatory standalone section. A separate story needs enough work and context to be interesting beyond a list of names.
