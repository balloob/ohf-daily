# Track: new devices and capabilities

Look across organization boundaries for things newly coming to the open-home ecosystem:

- new Home Assistant integrations, platforms, entities, and supported models;
- new Music Assistant providers and player support;
- new ESPHome components, boards, devices, and model variants;
- Matter.js, Z-Wave JS, Zigpy, Bluetooth, and device-library quirks or model support;
- companion translations, documentation, or discovery changes needed to complete the capability.

This track is not a daily quota. Propose it only when there is enough concrete material for a useful story and recent-edition context shows it has not become repetitive. Group related implementation PRs into one article. State clearly when work is groundwork and a downstream product has not implemented it. A genuinely new provider, integration, component, quirk, or device model can be celebrated, especially when it is a contributor's first contribution.
